A simple and efficient Library Management System for BCA students

📖 About the Project
BCA Student Library helps manage books, students, and borrowing records
in one place. It replaces manual registers with a fast, easy-to-use system.

## ✨ Features
- 🔐 Admin & student login
- 📕 Add, update, delete, and search books
- 👨‍🎓 Student registration and profiles
- 🔄 Issue and return books
- ⏰ Due dates and fine calculation
- 📊 Reports of issued and available books
